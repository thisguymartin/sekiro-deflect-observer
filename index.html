For players

Install and play

You need Windows x64, the Steam edition of Sekiro, and me3. You do not need Rust, Python, Visual Studio, or Cheat Engine.

  1. Close Sekiro completely.
  2. Download SekiroDeflectObserver-0.12.4-preview-windows-x64.zip and its .zip.sha256 file from the maintainer's release assets. GitHub's Source code archives and Code > Download ZIP are not playable mod packages.
  3. Compare the ZIP's SHA-256 with the downloaded checksum before extracting it. In PowerShell, run Get-FileHash .\SekiroDeflectObserver-0.12.4-preview-windows-x64.zip -Algorithm SHA256.
  4. Extract the complete ZIP to its own folder, such as C:\Mods\SekiroDeflectObserver. Keep the DLL, launcher, and profile together. You do not copy this package into the game directory.
  5. Install me3 using its official Windows release. See the me3 user guide for loader setup.
  6. Keep Steam running. Open observer.me3, or run launch-observer.cmd from the extracted folder.
  7. Load a save and lock onto a living enemy. Look for the top-center attack rail. Press F9 to check the loaded version.

Use one observer loading method per session. Remove the old observer .asi if you previously used the drop-in package. Preserve shared loader files used by other mods. Never overwrite another mod's dinput8.dll.

Show or hide the HUD

Press F8 to hide the rail, practice moon, and diagnostics panel. Press it again to show the HUD. Visibility is saved between launches. Hiding disarms practice. Showing does not re-enable slowdown.

Press F9 to switch diagnostics on or off. If diagnostics are on when you hide with F8, the panel returns when you show the HUD. Hotkeys need a fresh press while Sekiro is focused.

Practice at a slower enemy speed

Press F11 to enable practice. Press Shift + F11 to cycle 90% → 80% → 70% → 60% → 90%. The selected speed persists, but practice starts off every launch. For example, 70% speed means 30% slower enemy animation.

The moon is gray when off, gold when waiting, jade when an override is applied, and amber when attention is needed. You still press every defensive input yourself. The rail describes an animation phase, not a guaranteed deflect instant.

For the maintainer

Build the first downloadable package

Use a clean checkout of the exact revision you intend to release. Keep Cargo.lock, rust-toolchain.toml, and the vendored dependencies. Record git rev-parse HEAD with your test results. If you change the package version, update Cargo metadata and the versioned player instructions together.

Option A. Use the existing Windows workflow

  1. Push the candidate branch to the repository. Open the Windows proof of concept run for that exact commit under GitHub Actions.
  2. Wait for Build, test, and package to pass. Download the artifact named SekiroDeflectObserver-windows-x64 while signed in.
  3. Extract the outer Actions artifact. Keep the inner versioned mod ZIP and its checksum unchanged. Actions artifacts expire after 14 days in this repository. They are not a permanent release.

Option B. Build on your Windows machine

  1. Install Visual Studio Build Tools with Desktop development with C++, the MSVC x64 compiler, and the Windows SDK.
  2. Install Rust through rustup, and install Git.
  3. Open Developer PowerShell for Visual Studio in the clean repository checkout.
  4. Run the build command below. Stop if any check fails.
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1

The script checks formatting, runs Clippy and tests, builds the Windows release DLL, checks rejection of a non-game host, and packages the result. It uses the pinned Rust 1.94.0 toolchain.

target/x86_64-pc-windows-msvc/release/sekiro_deflect_observer.dll
dist/SekiroDeflectObserver-0.12.4-preview-windows-x64.zip
dist/SekiroDeflectObserver-0.12.4-preview-windows-x64.zip.sha256

The build replaces an existing ZIP with the same version in dist. Preserve any candidate you already shared before rebuilding. A repeatable procedure does not prove byte-for-byte reproducible output.

Check the candidate before sharing it

  1. Keep the build logs and source commit. Confirm the archive contains exactly these files at its root.

The package script reopens the ZIP and checks every file against staging. SHA256SUMS.txt lists the payload hashes. The separate .zip.sha256 hashes the whole ZIP. me3 is installed separately and is not bundled.

  1. Verify the ZIP checksum. Test a fresh extraction using only the packaged player instructions.
  2. On Windows with a physical GPU, check the F9 version and startup DLL hash. Lock onto an enemy and confirm the rail draws.
  3. With diagnostics open and practice on, press F8. Confirm every HUD element disappears and enemy speed restores. Press F8 again. Confirm the HUD returns, diagnostics return, and practice remains off.
  4. Check F11, all four speed presets, target switches, focus loss, death, loading, rest, and quit to title. Restart Sekiro and confirm saved visibility and speed, with practice off.
  5. Record the Windows version, GPU, driver, game executable hash, me3 version, and other mods. Complete the repository's gameplay checklist and release test procedure.

A macOS unit test or a successful Windows build does not verify live rendering, gameplay timing, or restoration during game transitions. Record these as pending until someone runs the game checks.

Publish the checked files when ready

These are manual steps for the maintainer. The build workflow does not publish a release.

  1. Create a release tag for the exact tested commit. Use the matching package version, for example v0.12.4-preview, only if that tag is unused. Do not move an existing release tag.
  2. In the repository's Releases page, choose Draft a new release and select that tag.
  3. Attach the tested versioned ZIP and its .zip.sha256 file. Do not upload the outer Actions artifact or substitute a source archive.
  4. Include the install steps, F8 and F11 controls, exact test environment, known limitations, and source commit in the release notes. Mark this preview as a pre-release.
  5. Save the draft and review its files. Publish only after the candidate checks pass and you decide it is ready.

Follow GitHub's release instructions for the current interface. Players should receive a release link with the compiled assets.

Fix a launch problem or remove the observer

  • me3 not found. Install me3, then open a new terminal or launch observer.me3.
  • DLL missing. Extract the whole mod ZIP. Do not launch files from inside the archive.
  • No HUD. Focus the game and press F8 once. Lock onto a living enemy. If still absent, inspect the logs in %LOCALAPPDATA%\SekiroDeflectObserver.
  • Old version still loaded. Close Sekiro completely, replace the extracted package, and relaunch through the intended profile.
  • Settings. Edit %LOCALAPPDATA%\SekiroDeflectObserver\cue.toml. The bundled cue.toml is an example, not the live settings file. The parry_button setting changes the LB, L1, or RMB badge only. It does not remap hotkeys.
  • Remove. Close Sekiro and stop using this me3 profile. Delete its extracted folder if desired, then launch normally through Steam. Keep shared loader files. F8 hides the HUD but does not unload the mod.
